`bin/run_WADERs` loads modules from `../src`; `src/` modules import each other from their own
folder; `utils/` are independent. Every script has `-h`. Nothing has hard-coded personal paths;
the reference JSON is embedded in `autoconfig_panaSKImg.py` (`REFERENCE_JSON`).

### run_WADERs (main entry point)
`run_WADERs INPUT [options]`, INPUT = image (.fz/.fits/.fits.bz2) or .txt list (one path per line,
relative to the .txt, `#` comments). Output: `WADERs_analysis_<image or list name>/` with PDFs,
`summary.txt`, `fit_quality.csv`, `root/` (cluster files per CCD + `root_files.txt`),
`root/dc_fits/`, `json/<image>/{gain,dc,final}/`, `logs/`.
- Finds the conda env itself if launched from a python without ROOT/pysimdamicm (`conda run -p`);
  `--env`, `$WADERS_ENV`, `--panaskimg`, `$PANASKIMG`.
- Per image: `gain_dc_split.split_image(per_ext=True)` -> per-CCD JSONs -> panaSKImg per CCD
  (`--acm --ext N --save-plots`) in parallel (`-j`, default 4) -> collect.
- Flags: `-o DIR`, `-j N`, `--overwrite`, `--all-ext` (also run flooded/unresolved CCDs),
  `--no-clusters` (drop ClusterFinder/BuildClusterMask; ~4x faster), `--tune` (per-CCD pedestal
  candidates ranked by total fit error + window refinement; ~+20-60 s/image), `--gain-correction`
  (+ `--gain-anchor comb|fit`, default comb), `--keep-work`, `--autoconfig-args "..."` (pass-through,
  e.g. `"--cluster-threshold-e 2 5"`, `"--peaks 1"`, `"--gain EXT1=1.33,EXT2=..."`), `-h` (flags),
  `-h -v` (full guide).

### autoconfig_panaSKImg.py (key behaviour)
- Measures each CCD from raw pixels: geometry (header PHYSCOL-NCOLPRE+PRESCAN; windowed readouts
  -> no overscan), dead channels, gain (histogram autocorrelation comb + refine), resolved?,
  bad columns, noise (row-aligned comb residual), DC per row (row_end where lambda > 1),
  Poisson-like peak count (k_poisson), overscan charge fraction.
- `--peaks auto` (default): fit only peaks that follow one Poisson (usually 0e-/1e-) -> unbiased DC.
  `--peaks 1`: only the zero-electron peak (noise only, window -4..+1 sigma, DC held ~0, gain +-2%).
- Pedestal rule: median of overscan per row by default; lowest-peak finder (is_highDC, 150 bins)
  only if most fit rows have charged overscan; active-region median if no overscan or fallback.
- `--per-ext`: one JSON per CCD (own pedestal method/window/binning; peak count stays module-wide)
  + `run_<image>.sh`. `*_measured.json` sidecar: lam01 (DC from 0e-/1e- counts), skip flag.
- `--tune`: candidates ranked by total fit error (fit_quality: errors scaled by sqrt(chi2/ndf) +
  DC bias vs lam01; +1 penalty for parameters at limits); then refine_peaks on panaSKImg's own
  histogram. Works with `--per-ext` (CCDs in parallel threads).
- Fallback (new 2026-10-16, `--no-fallback` disables): only for CCDs the comb search calls
  unresolved. If, with an active-region pedestal and the clean early rows (first ~30, zero peak
  holds >=20%, no baseline step between row halves), the zero-peak width (left side, +-1.5 gain)
  is < 0.3 x gain: treat as resolved, fit 0e-/1e- with gain held +-0.5% at the prior (`--gain` or
  reference default), pedestal from the active region.
- Writes `x_max_plot` (wider DC-fit plot) only if the installed pysimdamicm supports it
  (`panaskimg_has_plot_range()`); an unknown key makes panaSKImg crash.
- Outlier CCDs (unresolved among resolved, e.g. flooded) get unreachable ClusterFinder thresholds
  and are skipped by the per-CCD run script.

### gain_vs_charge.py
- `measure IMAGES -o DIR`: local gain from the electron comb (periodogram of pixel values in
  charge windows 20..7000 e-), clean rows only (blocks of 25 rows whose 1-30 e- comb visibility
  >= 0.6 x max). Model `g(n) = a + b*min(n, n_cap)`, n_cap = 3 x highest measured charge
  (`--extrap-factor`). Rejected (no correction) if < 4 significant bins, n_max < 400 e-, or b > 0.
- `apply MODEL.json ROOT... -o DIR [--anchor comb|fit]`: pixel keV = ADU/g_fit*3.74e-3 in panaSKImg;
  recompute pixels_E and Energy via A^-1 (integral of g). `comb` (default) uses the comb's whole
  curve incl. low-charge gain a; `fit` keeps each image's fitted gain and corrects only the slope.

## 7. Known issues and open items
- **Gain correction coverage**: ~20% of CCDs get no reliable g(n) (comb fades after 1-3 charge
  bins). Ideas: measure g(n) from a higher-statistics image of the same module/day and reuse it
  (apply supports any model JSON); per-row-block baseline correction to keep the comb visible.
- **Residual -0.2..-0.7%** after correction: charge in the faint cluster edge dropped by
  ClusterFinder's threshold (noise-based ~10 sigma); back-side clusters lose more. Not a gain issue.
- **g(n) extrapolation** (x3 of measured range) was chosen on AMT data; only weakly tested for
  very compact clusters (AMT EXT1 depends on the model shape).
- **Windowed images**: supported but correction less reliable; July 2025 runs have ~no Fe-55.
- **Am-241 PD06/DM12 (2026-03-28)**: 5/6 CCDs no resolved peaks -> not corrected.
- **10000-skip image**: noise physically worse; repeat the measurement (and a 5000 right after) to
  separate "more skips" from "worse conditions"; per-skip raw data would show the noise spectrum.
- **Autoconfig ideas not implemented** (user said hold): robust row exclusion when overscan is
  contaminated in general (the fallback covers only unresolved CCDs).
- panaSKImg issues noted, not fixed (user did not ask): SetParameters 6-of-7 bug; TF1 100-point
  drawing; `.fits.bz2` file-name parsing (our scripts decompress); ACM ccd_cols conventions.
- PATH `/bin` update pending user action; old `noise_img*.json`/`autoconfig_reference.json` unused.
